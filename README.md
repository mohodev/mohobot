## 1. MDUI 是什么？

MDUI 是 **MohoBot 官方设计的一套基于 Markdown 的 WebUI 框架**，特点：

- 完全使用 Markdown 描述界面
- 支持动态组件
- 轻量级
- 参考 AstrBot 的插件系统
